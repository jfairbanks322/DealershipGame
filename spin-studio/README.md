# Spin Studio

A standalone, customizable classroom prize wheel. It has no external services, packages, fonts, or image dependencies.

## Run it

1. Open a terminal in this folder.
2. Run `npm start`.
3. Open [http://127.0.0.1:4173](http://127.0.0.1:4173).

You can also open `index.html` directly for simple offline use.

## Included classroom features

- 2–24 slots with fast Enter-to-add
- randomized Regular (3–8 seconds), Medium (8–14 seconds), and Long (14–22 seconds) spin lengths
- inline slot renaming, deletion, shuffling, and regular/wildcard conversion
- one-dropdown wildcard creation
- automatic backward and 2×-speed follow-up spins
- automatic Tiny Wheel and GIANT WHEEL follow-up spins that resize the live wheel
- movement, wheel-flip, swap, teacher-choice, and double-reward wildcards
- mature charcoal-and-metal visual style with muted colors and subtle worn texture
- a three-spin wildcard-chain safety limit
- automatic saving of the title, slots, wildcard actions, spin length, and sound setting on the device
- winner controls to clear only the landed slice or every slice with the same text
- nearly full-screen result and wildcard announcements sized for classroom projection
- a one-click wheel-only view that hides the editor during class
- mouse, touch, Space-key, and fullscreen controls
- responsive projector, laptop, tablet, and phone layouts

No slot data is sent anywhere; everything stays in the browser on the current device.
